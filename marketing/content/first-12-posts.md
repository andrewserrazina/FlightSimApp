# Turnline — First 12 short-form posts
Prepared 2026-10-11. Start only after working waitlist and naming clearance. Until then, CTA is **Follow development**, not join a nonfunctional list.

**Production rules:** 9:16, 1080×1920, 15–35s typical; first readable visual in 1.5 seconds. Real product footage only when actually recorded; concept footage visibly stamped `CONCEPT — NOT RELEASED`. No fabricated customer results, real-world ATC authority, or working GSX/SimBrief claims. Publish TikTok and IG Reels natively; test YouTube Shorts selectively. Each post has one CTA. Record caption separately from burned-on text.

## Distribution and cadence
- Mon/Wed/Fri at a consistent experimental time; no claim that a posting hour is optimal.
- One source capture, native versions for TikTok/Instagram, test Shorts with the same core hook.
- Name each clip `TL-W01-P01` … `TL-W04-P12`. Use UTM campaign `prelaunch_2026_wXX` and content `pXX`.
- Respond to technical questions; never promise specific compatibility until Windows testing passes.
- At 24h and 7d log reach, 3s hold, completion/watch time, profile visits, site visits, confirmed leads, and qualified comments where available.
- For launch teasers, avoid using an unrelated training brand's customer email list unless separately consented.
