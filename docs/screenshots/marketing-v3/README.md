# Marketing site V3: before and after

Captured with `scripts/marketing-compare-screenshots.mjs` (Chromium, reduced motion, signup endpoint blocked, Turnstile
test key). The full-page captures are WebP (desktop) and JPEG (mobile, too tall for WebP) to keep the repository small.

| File | Shows |
|---|---|
| `before/*` | The V2 site from `main` at 800ecd3 |
| `after/*` | The V3 site on `feature/marketing-v3` |
| `*-first-screen.png` | The first screen at 1440×900 (desktop) and 390×844 (mobile) |
| `desktop-full.webp`, `mobile-full.jpg` | The whole page |

The product screenshots used on the site are in `marketing/assets/screens/`; how they were made is described in
`marketing/README.md` (V3 → Screenshots).
